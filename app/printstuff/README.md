# PrintStuff Ordering Module

Build the new PrintStuff custom ordering website in this repository.

Customer:
- B2B catalogue
- Product customizer
- artwork upload
- bulk pricing
- cart / checkout
- order ID and tracking

Admin:
- secure login
- dashboard
- order list/search/filter
- order detail + artwork
- status pipeline:
  Order Received -> Artwork Review -> Production -> Printing -> Quality Check -> Dispatched -> Delivered
- notes and CSV export

Catalogue source: supplied PrintStuff B2B PDF. Products/prices: Zipper Hoodie 320 GSM (600/550/525/500), Regular Hoodie 320 GSM (550/525/500/475), Normal Polo 180 GSM (450/400/380/350), Premium Polo 220 GSM (475/450/410/380), Crew Neck T-Shirt 180 GSM (450/400/380/350), Cap (250/230/210/190), for quantity tiers up to 10/up to 20/up to 50/50+. Shipping extra. Apparel sizes S, M, L, XL, XXL; cap is universal free size.
