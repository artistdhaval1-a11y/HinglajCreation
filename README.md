# Hinglaj Creation

Ecommerce storefront for Hinglaj Creation — custom men's kurtas with Plain, Patch Work, DTF Print and Print + Patch collections.

## Stack
- Next.js
- React
- TypeScript
- CSS
- Render deployment

## Development
```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Planned ecommerce features
- Product catalogue and filters
- Product detail pages
- Cart and checkout
- Custom kurta builder
- Order management
- Online payments
- Admin dashboard
